Dentist Clinic Simulation -\/ Operating System Project.

This program simulates a dentist clinic using different Operating System concepts.

Main OS Concepts\+:
\begin{DoxyEnumerate}
\item POSIX Threads
\item Mutex
\item Semaphores
\item FIFO / FCFS Scheduling
\item Critical Section
\item Synchronization
\item Structure
\item Pointer
\item Dynamic Memory Allocation
\end{DoxyEnumerate}

Main Features\+:
\begin{DoxyItemize}
\item Patient management
\item Appointment management
\item Waiting room management
\item Doctor treatment management
\item No-\/show patient handling
\item FIFO / FCFS scheduling
\item Thread synchronization
\item Mutex protected critical sections
\item Semaphore based communication
\end{DoxyItemize}

User Input\+:
\begin{DoxyItemize}
\item Number of patients
\item Number of waiting room chairs
\item Doctor capacity
\item Number of appointment slots
\item Patient names
\item Patient arrival / no-\/show status
\end{DoxyItemize}

Special Rule\+: If a confirmed appointment patient becomes a no-\/show, the appointment slot is released and another waiting patient can receive treatment.
